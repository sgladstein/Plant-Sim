# Plant-Sim

A simulation-first plant growth sandbox: watch plants grow from seed in sped-up time, with the science visible through toggleable lenses, and later breed them from seeds.

Start with [docs/design-plan.md](docs/design-plan.md). It is the complete v3 plan: experience, simulation model, data formats, milestones and work packages, validation targets, architecture, and the implementation guide for the first coding session (section 11).

No code yet. The first work package is WP0 in section 7 of the plan.
